# 💰 Expense Tracker

A modern and responsive Expense Tracker built with **React** to help users manage their income and expenses efficiently.

## 🚀 Features

- ➕ Add new transactions
- ❌ Delete transactions
- 💰 Real-time balance calculation
- 📈 Income & 📉 Expense summary
- 📱 Responsive and modern UI
- ⚡ Global state management using Context API and useReducer

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- CSS3
- React Icons
- Context API
- useReducer

## 📦 Installation

```bash
git clone https://github.com/Tammina-Prasad/expense-tracker.git

cd expense-tracker

npm install

npm start
```
